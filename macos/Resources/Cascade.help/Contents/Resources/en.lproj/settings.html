Cascade Help

Settings

Open Settings from the Cascade menu. Changes to polling, Jira and worktree options take effect when you click Save.

General

  • Appearance: light or dark.
  • Startup: launch Cascade at login.
  • Microphone: allow voice input in terminals and agents.
  • New session agent: the agent new sessions start with.
  • Notifications: the Review sound, Activity notifications and notification permission.
  • Open in git client: your Git app, or a custom Command template.

Browser

  • Block ads with uBlock Origin Lite.
  • Clear History… and Clear Cookies…
  • Page memory: when pages use more than this, the least recently used hidden page is suspended.

Worktrees

  • New worktrees: next to the checkout, inside it, or in a folder you choose, per project.
  • Fetch before creating: fetch the base branch first (off by default; gives up after 8 seconds and uses the local branch).
  • Copy ignored files such as .env files, or those listed in .worktreeinclude, into new worktrees.
  • Delete merged branch when a worktree is removed.

Terminal

  • Session memory: above this, the least recently used idle agent is stopped.
  • Font smoothing, color theme and font.

Text Editor

  • Show code preview (minimap), color theme and font.

Integrations

  • Setup Assistant and the sign-in status of each command-line tool.
  • Forward webhooks to automations.
  • Simulator preview.
  • GitHub poll interval (60 seconds by default) and Jira poll interval (120 seconds).
  • Jira: site URL, result limit and API token.
  • Workflow hooks and the agent context status line.

Shortcuts

Change the key for any command, or restore its default. See Keyboard shortcuts.

System

  • Resource Usage: CPU and memory used by Cascade and its sessions.
  • Diagnostics.

Activity

A log of everything Cascade did in the background: syncs, notifications, automations and transitions.
