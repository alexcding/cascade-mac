Cascade Help

Data, updates and troubleshooting

Cascade keeps everything on your Mac and updates itself.

Updates

Cascade checks for updates automatically. Choose Cascade → Check for Updates… to check now. Updating restarts Cascade, which stops running terminals.

Where your data lives

Everything is in ~/Library/Application Support/Cascade.

FileContainsSafe to delete?
cascade.dbProjects, sessions, tabs and settingsNo: back it up
data.dbCached GitHub and Jira dataYes, it is rebuilt
logs.dbThe Activity logYes

Backups

Before the first launch of each new version, Cascade saves a checkpoint in native-backups/ inside the data folder. These are not deleted automatically.

To make a backup yourself, save open files, quit Cascade, then run:

/Applications/Cascade.app/Contents/Helpers/cascade-backend backup <destination>

The same tool has verify and restore. The destination must not already exist. To go back to an older version, restore a checkpoint taken before the upgrade and use that older app. Worktree files and agent conversations are not part of the backup.

Links into Cascade

Other apps and scripts can open Cascade at a specific place:

LinkOpens
cascade://app/overviewThe Overview
cascade://app/automationAutomation
cascade://app/terminalThe terminal
cascade://app/projects/<id>A project
cascade://app/projects/<id>/prsA project's pull requests (also tickets, board, workflows, settings)
cascade://app/sessions/<id>A session

Troubleshooting

Pull requests or tickets are missing

Check that gh auth status and acli jira auth status report you as signed in, or look at Settings → Integrations. Then press ⇧⌘R. If a refresh fails, Cascade keeps the last good data and offers Retry; Settings → Activity shows what went wrong.

The Sprint board has no columns

Add a Jira API token in Settings → Integrations → Jira.

Automations are slow to react

Without webhooks they run on the polling cycle (every minute by default). Install the extension with gh extension install cli/gh-webhook and turn on Forward webhooks to automations.

My sessions kept running after I closed the window

That is intended. Closing the window leaves sessions running; Quit (⌘Q) stops them.

Cascade is using a lot of memory

Lower Session memory in Settings → Terminal and Page memory in Settings → Browser, and check Settings → System → Resource Usage.

Voice input does not work in a terminal

Allow microphone access in Settings → General → Microphone.
