Cascade Help

The session workspace

Each session has a terminal, a browser, a file editor and a view of its working changes, side by side.

Terminal

  • Terminals are real Ghostty terminals run by a separate background process. They keep running when you close the window and survive an unexpected quit. Choosing Quit stops them.
  • Drop files or images onto a terminal to type their paths.
  • Links a command-line tool opens appear in the panel beside the terminal.
  • Voice input works in terminals and agents once microphone access is allowed in Settings → General.
  • Go to the terminal with ⌃⌘T.

Browser

  • Tabs, bookmarks, history, downloads and Find in Page… (⌘F).
  • New tab ⌘T, new sidebar tab ⌥⌘T, reload ⌥⌘R, close ⌘W.
  • Ad blocking with uBlock Origin Lite, set in Settings → Browser.
  • Plain http sites and local development servers open too.

Files and the editor

  • Search the worktree, reopen recent files and read code with syntax highlighting.
  • Open File… ⌘O, Save File ⌘S. Closing an edited file asks you to Save, Discard or Cancel.
  • The editor handles UTF-8 text files up to 5 MB. Files that cannot be written safely open read-only.
  • Turn on Show code preview in Settings → Text Editor for a minimap.

Working changes

  • See every change in the worktree, and discard a single change block after previewing it.
  • Search the branch history.
  • Commit and Push, optionally including untracked files. Cascade warns you when the branch is behind its upstream.

Xcode projects and the Simulator

  • Pick a scheme and destination, then Product → Run (⌘R) and Stop (⌘.).
  • Stream a booted iOS Simulator into the session while the agent works. This needs Node.js 20 or later; see Settings → Integrations → Simulator preview. The stream runs only while that session is on screen.
