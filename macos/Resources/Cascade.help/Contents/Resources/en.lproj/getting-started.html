Getting started

Cascade is a native app for Apple silicon Macs running macOS 14 or later. It works through the command-line tools you already use.

The setup assistant

On first launch Cascade checks each tool, shows how to sign in where needed, and offers to install agent hooks so it can follow what your agents are doing. You can run it again any time from Settings → Integrations → Setup Assistant.

Add a project

Choose File → New Project… (⌘P). A project is one GitHub repository plus its local checkout, and can optionally carry a Jira JQL query, a color and a background setup script that runs in each new worktree.

Removing a project keeps its workspace folders and sessions on disk.

Start working

Press ⌘N to start a session, or open the Overview (⇧⌘H) to see what needs your attention.
