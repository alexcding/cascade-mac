Jira and the Sprint board

Each project can follow a Jira JQL query. Cascade reads and updates tickets through acli.

Tickets

  • A project's ticket list comes from its JQL, with search and filters.
  • Use a row's status menu to move a ticket to another status.
  • Right-click a ticket to open it or start a session on it.

Sprint board

  • Drag cards between columns, move and reassign tickets, and filter by assignee.
  • Board columns come from your Jira board, which needs a Jira API token.

Jira API token

Create a token at id.atlassian.com and paste it in Settings → Integrations → Jira → API token. It enables board columns and setting Fix Versions from automations. Cascade finds your Jira site URL from acli, and Result limit caps how many tickets it fetches (100 by default).
