Cascade Help

Dashboard and menu bar

Cascade keeps a fresh snapshot of your pull requests and tickets in the background, so the dashboard opens instantly.

Overview

Open it with ⇧⌘H. Tiles show your open pull requests and failing CI, reviews waiting on you with the oldest wait, your assigned tickets by stage and the last 30 days of AI spend. Click a tile to drill in.

The Pull Requests, Reviews and Tickets tabs list everything, with one search across all of them. Right-click an item to open it in a tab or start a session on it.

The Reviews section includes pull requests you have been asked to review and ones you have already reviewed but that are not yet done.

Agent usage

See Claude Code and Codex rate limits for the current session and the week, next to your AI spend.

Refreshing

Cascade checks GitHub every minute and Jira every two minutes. Change both in Settings → Integrations → Polling. Press ⇧⌘R to refresh now. If a refresh fails, Cascade keeps showing the last good data and offers Retry.

Menu bar

The menu-bar icon shows review requests, CI status and agent usage. Open it with ⇧⌘U (Reviews & Usage). The icon turns bronze while a review is waiting for you.

Notifications and Activity

Cascade notifies you about new review requests (with a sound you can change in Settings → General), merged and closed pull requests and Jira transitions. The bell in the sidebar shows today's events; the full log is in Settings → Activity.
