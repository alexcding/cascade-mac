### Improved

- Your sidebar tabs, page tabs, preferences and board filters are kept by the app itself, so changes save at once. What you had is carried over the first time you open this version.
- GitHub syncs run at most four at a time, so a burst of projects no longer holds up what you are waiting on.
- When the app misses updates from a busy sync, it reloads instead of showing out-of-date data.
- Diagnostics in Settings refreshes itself while it is open.

### Fixed

- Ticket stages are read by whole words. "Unblocked" no longer shows as Blocked, and "Abandoned" or "Undone" no longer show as Done.
- A project whose sync failed no longer looks freshly synced, and the dashboard says why instead of "waiting for the first sync".
- A sync that was still running when its project was changed or removed no longer writes its old results back.
- A new session reuses an existing worktree folder only when it is on the same branch.
- Sample tickets in an automation's preview come from the project's board again.
