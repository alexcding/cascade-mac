### Improved

- New Task: paste a pull request, issue or Jira link with words before or after it. The link picks the session's branch and worktree, and everything you typed, link included, is the agent's first message. A link on its own is sent too, so the agent starts by reading it.
- A scheme you pick in a session's run destination menu becomes the project's default, so the next session starts on it instead of on the first scheme the project ever ran.
- Start a chat without typing anything first. It opens and waits for your first message.
- A paired Mac shows in the sidebar only while it is online. Settings → Remote still shows each Mac's state.

### Fixed

- A link followed directly by `。` or `，` is recognised.
