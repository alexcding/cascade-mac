### New

- Chat with Claude or Codex without a terminal: New Task has a Task | Chat switch, and a chat needs no project or folder.
- A chat streams its replies and asks you before running tools, and you can change its model or permissions mid-chat.
- Fork a chat from any message, edit an earlier message, or revert a turn, which undoes only that chat's own changes.
- Work an agent hands to a subagent shows in a thread of its own, opened from the chat.
- A session's pane has Chat tabs: chats that work in the session's worktree, optionally starting with what the session's agent already knows.
- Attach files to a chat with the + button, a paperclip, paste or a Finder drag; images are sent to the agent, and other files go by their path.
- A session's pane has Terminal tabs, each a shell of its own in the worktree.
- Chats appear in the sidebar and on Overview, titled after their first message.

### Improved

- Overview lists each project's sessions in a table, with a tag for each session's status.
- Project folders have new icons, and a gear on the folder under the pointer opens Project Settings.
- ⌘+ and ⌘− resize every chat together.
- Pane tabs widen as they open and fold away as they close.
