### New

- Open sessions stay alive when you switch between them in the sidebar, so coming back to one is instant, with its terminals, pages and scroll positions as you left them.
- Optional memory limits in Settings. Page memory suspends the least recently used hidden web page, which reloads with its history when you open it again. Session memory stops the least recently used idle agent, which resumes its conversation when you open its session.
- Codex usage limits are read live from the Codex CLI, falling back to the last ones a session recorded when it is unavailable.

### Improved

- The iOS Simulator preview streams only while its session is on screen.
- Terminals send each window only the events it shows and drop clients that stop reading, keeping busy sessions responsive.
- Closing the last page of a panel no longer closes its tab.
- The dashboard's side column lines up with the tiles.

### Fixed

- Resource usage counts only processes a session started itself.
- A suspended page keeps its back and forward history.
- A session whose agent fails to stop is detached instead of left stuck.
- Codex usage ignores server requests that reuse a reply's ID.
