### New

- Projects can have their own icon again: pick any SF Symbol in the project's settings, or Use Folder to go back to the folder. The sidebar and Overview both show it.
- A closed project shows how many sessions it holds at the end of its row.

### Improved

- Settings → Worktrees → Worktree cleanup lists only worktrees no session works in. The list shows at once and fills in sizes after, measuring each worktree once.
- Worktrees on a drive that is not mounted are left alone by cleanup.
- The sidebar's Today menu spans the sidebar's width, and clicking the activity capsule only opens it.
