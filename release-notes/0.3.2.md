### New

- Agents can show interactive charts, tables, checklists and calculators right in their chat replies.
- Agents can drive the iOS Simulator, from a chat or from a session's terminal: boot a device, install and launch your app, tap, type and swipe, read the screen and its logs, and take screenshots.
- The Simulator tab streams the device live, takes clicks, drags, typing and the hardware buttons, and shows when an agent is using it.
- Pair another Mac once with a 6-digit code in Settings → Remote, and see its projects and sessions in a sidebar section of their own.

### Improved

- The chat is up to date with Synara's latest client, including dragging files from the editor into the composer.
- Activity is now a bell in the toolbar, next to the sidebar toggle.
- A long-running command in a chat shows one progress line that keeps updating, instead of a new line each time.
- When an agent's CLI crashes, the chat shows the last lines it printed.

### Fixed

- A Claude chat turn that ends in an error now shows as failed, not finished.
- Stopping a chat turn while Claude is shutting down no longer leaves the turn stuck.
