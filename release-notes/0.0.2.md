### New

- Automations: a new sidebar screen for pipelines that run across all your projects. Pick a trigger (PR opened, CI passed or failed, review requested, approved, merged, a Jira ticket changing status, and more), filter it, then chain GitHub and Jira actions such as approve, comment, label, merge, re-run failed checks or transition a ticket.
- Each project's existing merge automation (Jira transition and Fix Version) carries over as a live pipeline, so nothing you set up stops working.
- GitHub webhooks can forward pull request events to automations as they happen; turn it on under Settings → Integrations.
- Links opened by command-line tools in a terminal open in the panel beside it.
- Drop files or images on a terminal to type their paths.
- Rename a session from its right-click menu in the sidebar.
- Choose the project's editor when creating a new project.

### Fixed

- An automation approves a pull request at most once per commit, and a save no longer affects other pipelines' rows.
- Links from a terminal whose session is not open now go to your default browser instead of nowhere, and web pages can no longer ask Craft to open links.
- The tab you are renaming no longer drags, and the rename field is focused and stays put during a refresh.
- A long session title no longer overflows the toolbar under the scheme.
