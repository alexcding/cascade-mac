### New

- Chat view for agent sessions (preview): a button in the session toolbar switches between the terminal and a chat of the conversation, with the agent's replies, thinking and tool calls shown as messages.
- Approve or deny an agent's tool requests from a card in the chat; anything left unanswered falls back to the terminal prompt as before.
- Attach files to a chat message with the paperclip, by dropping them on the message box, or by pasting a screenshot. Each sits in the message as a chip that Backspace removes, and they are pasted into the terminal ahead of the message, as a drop onto the terminal would.
- Type `/` at the start of a chat message for the agent's commands, including your own, the project's, skills and plugin commands, and `@` for the worktree's files. Arrows move through the list, Tab or Return take a row, and Escape closes it. A command that opens a panel, like `/model` on its own, switches to the terminal.
- The terminal keeps running behind the chat, and each session remembers which view it was left in.
- Help → Cascade Help opens a built-in guide covering setup, the dashboard, sessions, Jira, automation, settings and shortcuts.
