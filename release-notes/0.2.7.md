### Improved

- Each session runs on a simulator of its own. A session's first Run makes a copy of the simulator it would have run on, named after the session, so two sessions no longer share one screen or replace each other's app. The simulator is deleted with its session. A destination you pick in the run destination menu is still used as it is.
- Switching between sessions shows each one's simulator at once, rather than loading its stream again.
- The run destination menu lists connected devices and simulators under their own headings, as Xcode does. With nothing saved, Run no longer picks a plugged-in iPhone: this Mac or a simulator comes first.

### Fixed

- The Simulator panel takes taps, typing and buttons again on Xcode 27. The first preview after updating downloads the new preview helper, so it takes a few seconds longer.
- Cascade appears under System Settings › Privacy & Security › Microphone, and web pages and terminal sessions can ask for the microphone, camera and Apple Events again.
