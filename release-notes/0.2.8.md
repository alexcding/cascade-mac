### New

- A chat started from New Task can work in a project. The Chat side has the same project chip as the Task side, without a branch: pick a project and the agent works in its folder as it is, or keep No Project for a scratch folder of the chat's own. Chats start in No Project, and the project you pick stays for the next chat until you quit.
- New Project offers to make a folder that isn't a git repository into one, committing its files, since sessions run in git worktrees.

### Improved

- New Project from the Chat side's project chip starts the chat in the new project.
- With no projects yet, New Task shows its usual composer, and the project chip offers New Project.
- Moving a project to another folder in Settings checks that the folder is a git repository, and offers to make it one, as New Project does.

### Fixed

- Making a folder a git repository works on a Mac with no git name or email set, and never waits on commit signing or hooks.
