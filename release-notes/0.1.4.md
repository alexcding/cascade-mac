### New

- GitHub issues assigned to you appear in My Tickets beside your Jira tickets. A project can turn this off in its settings.
- Every session starts from a project's Start tab: describe the task and press Return. Shift-, Option-, Control- or Command-Return adds a line. It replaces the New Session sheet.
- A project's page has tabs in the toolbar for Start, Board, Orchestration and Settings. The sprint board now lives on the Board tab; turn it on with Show board in the project's settings.
- The Dashboard's Pull Requests tab filters by Mine, To review and Others, and by project, and takes the place of the separate review tab. Tickets splits the same way into Mine and Others.
- The menu-bar icon shows how much of your agent usage is left, beside the glyph.
- The chat says what the agent is doing, such as running a command, reading, editing or searching, instead of a generic tool call.

### Improved

- The chat appears as soon as a session opens, and a message written before the agent is ready sends once it is. Messages sent while Claude is working reach it straight away, and the chat glides to a new prompt instead of jumping.
- The workspace's panels are picked from one group in the toolbar, web pages and open files share one row of tabs, and the side pane's tabs sit in the title bar, as in Xcode.
- Sidebar section headings have a new look, with New Project beside them.
- A new project guesses its IDE from the folder you choose.
- Installed agent hooks bring themselves up to date when Cascade starts, with a notification each time, in place of the notice in the chat.
- A project's Jira tickets are scoped by its project key, with an optional filter clause. Saved JQL queries and project workflows have been removed.

### Fixed

- The chat follows its own session's conversation rather than the newest one in the worktree, and a tool call still running stays marked as running when later ones finish first.
- After Cascade restarts, a session whose shell kept running shows at once whether its agent is working or waiting.
- Sidebar rows no longer vanish on a slightly moving click, and switching sessions keeps the side pane and its size right.
