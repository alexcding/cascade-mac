### New

- Cascade and its built-in help are now available in Bengali, Chinese (Simplified and Traditional), French, Hindi, Italian, Japanese, Korean, Portuguese (Brazil), Russian, Spanish and Swedish.
- Attach files to a chat message with the paperclip, by dropping them on the message box, or by pasting copied files or a screenshot. Each sits in the message as a chip you can delete, and Undo brings it back.
- Type `/` at the start of a chat message for the agent's commands, including your own, the project's, skills and plugin commands, and `@` for the worktree's files. Arrows move through the list, Tab or Return take a row, and Escape closes it.
- ⌘J switches a session between the terminal and the chat (Product → Switch Terminal / Chat), and can be rebound in Settings → Shortcuts.
- Scrolled up in a chat, a round arrow button takes you back to the latest message.
- Settings → Integrations lists every project with the status of its webhook forwarding, and a project can turn forwarding off in its own settings.

### Improved

- The chat's model picker and command list come from Claude Code itself, so they match the version you have installed. Picking a model with no effort level leaves the effort to Claude again.
- Chat zoom is one size for every session, kept across launches, and a change reaches every open chat at once, like the terminal font.
- A link clicked in the chat opens in the session's browser panel beside it.
- The automation list and editor can be resized, and long pipeline names are no longer cut off.

### Fixed

- A project whose webhook forwarding was blocked by a forwarder left behind after a quit or crash now offers Fix, which clears it and starts forwarding again.
- Sessions follow a switch between the system's light and dark appearance.
