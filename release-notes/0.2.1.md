### New

- A Workflow tab draws a session's agent as a live diagram: its tools at work, each subagent it starts, the files it last changed and the session log, in one of four themes.
- Start a session on an existing branch: pick the branch in the project's composer and it is checked out in a new worktree.
- A stopped session's sidebar menu has Reattach Session.
- A translucent window option in Settings puts the sidebar's background behind the whole window, terminals included, with an opacity slider.
- The session toolbar shows how full the agent's context is as a percentage.

### Improved

- GitHub and Jira refresh while you look: when you open the dashboard, a board or the menu bar item, when you come back to the app, and every minute while it stays in front. In the background nothing is fetched, except for projects an automation watches.
- The dashboard says how long ago its pull requests were updated.
- When GitHub or Jira stops answering, saved data stays on screen with a notice, Cascade waits longer between retries, and Activity is no longer filled with errors.
- Changes that came in while you were away are summed up in one quiet Activity line instead of a burst of notifications.
- Diff, the Simulator, Files and Workflow are tabs in the pane's one strip, opened from New Tab, which is always there; the button at the window's edge shows and hides the pane.
- A project's tabs and its Terminal toggle are standard toolbar controls, and the terminal slides in and out from the bottom.
- Each session in the sidebar has a branch icon before its name, and its status dot is always shown: grey when idle, blinking softly while the agent works.
