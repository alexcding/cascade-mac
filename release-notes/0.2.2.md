### New

- Scheduled automations start an agent on a project at set times: every few hours, daily, on chosen weekdays or by a cron line, with an optional precheck script that can skip a run, and Run Now to start one at once.
- Automations are listed in a table with each one's project, next and last run and status, searchable and filtered by Scheduled or Events, with templates to start from.

### Improved

- Pull requests refresh as soon as a forwarded GitHub webhook reports a change, even when nobody is looking, while staying within GitHub's rate limit.
- A scheduled run is marked failed when its agent does not start, instead of waiting for ever, and older run worktrees with nothing unsaved are cleaned up, keeping the last five.
- Prompts and precheck scripts are typed without smart quotes, dashes or autocorrect, so shell commands stay intact.
- Sessions in the sidebar lead with their status dot, icons are sized to fit each area, and session names and headings use a lighter type.

### Fixed

- My Tickets no longer drops a fresh search result when a refresh fails at the same time.
