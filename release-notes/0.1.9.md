### New

- A picker at the right of a session's toolbar opens the side pane on Tabs, Diff or the Simulator, and hides the pane when you choose the selected one.
- Web pages and open files share one tab strip in the pane, and files have Back and Forward.
- Clicking a pull request or ticket anywhere in the app goes to its session, or opens a new session for it with the link and its Jira ticket filled in.
- Pull request and ticket rows on the dashboard have Open in Browser.
- Each session in the sidebar shows its agent's state as a dot, which breathes while the agent is working.

### Improved

- The Diff pane keeps its review bar on top and refreshes by itself when files change.
- Reload and Bookmark always stay in the browser's toolbar, disabled when there is no page.
- Run starts your app with the arguments and environment set in the scheme, including when Cascade builds itself.
- The sidebar is lighter, with smaller row icons and no tabs of its own, and the editor no longer shows a code minimap.

### Fixed

- A Claude session stays marked as working while one of its background agents is still running.
- Committing in a terminal no longer fails because the Changes pane was reading the repository at the same moment.
- The editor keeps its width while a divider is dragged.
- Files whose names contain + are found again.
