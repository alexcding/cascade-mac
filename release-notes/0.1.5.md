### New

- Files are drawn with VS Code icon themes. Cascade comes with vscode-icons; install others in Settings → Text Editor → File Icons by pasting a VS Code Marketplace or Open VSX link.
- The working changes list their files in a folder tree beside the diff, with each file's added and removed lines. Choosing a file scrolls the diff to it.

### Improved

- Commit opens in a popover that shows the branch and how it stands against its upstream. Push appears once there is something to push.
- History lists the branch's own commits first and loads older history as you scroll.
- The code editor wraps long lines, and the code preview is off unless you turn it on in Settings.
- Recently added text is translated into every language Cascade supports.
