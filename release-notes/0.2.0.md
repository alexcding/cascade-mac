### New

- A project's page can open a quick terminal in a split beneath it, in the project's checkout or any of its worktrees, with no session needed.
- Choose an SF Symbol as a project's icon.
- Quitting while an agent session is still running asks you to confirm first.

### Improved

- Commit works from the Diff pane's History view too, not only Changes.
- The Diff pane's review bar is plainer, without the glass effect, and has a toggle for the changed-files list.
- File trees show Finder's folder and file-type icons.
- A session's status dot sits at the trailing edge of its sidebar row and ripples while the agent is working.
- Reload sits inside the browser's address field, and Open in Browser follows Bookmark.
