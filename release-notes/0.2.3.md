### New

- Projects is one page with Overview, Pull Requests, Tickets and Board tabs along its top, and a project menu that narrows every tab to one project.
- Overview shows each project with its sessions: what each agent is doing, the pull request on its branch with its checks and size, and whether it is waiting on you.
- A session board sorts every session by what it needs next: Needs you, Working, In review and Idle. Click a session to open it.
- New Task (⌘N) is the sidebar's first row: pick a project and branch, type a task, branch name or link, and choose the agent with its model and effort.
- The Files tool opens as many tabs as you like, each with its own tree, as web pages do.

### Improved

- Overview's top cards have a roomier look, and long titles wrap instead of being cut off.
- Project rows in the sidebar are simpler: a click opens or closes the folder, and New Task sits on the folder under the pointer.
