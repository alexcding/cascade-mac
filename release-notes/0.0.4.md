### New

- ⌘1–⌘9 and ⌘0 open the first ten sessions in sidebar order, and ⌘[ / ⌘] move to the previous and next session. The session's terminal takes focus right away.
- Holding ⌘ shows each session's shortcut in place of its agent icon.

### Improved

- Terminals open much faster: the shell starts the agent itself once your startup files have loaded, instead of waiting a fixed delay and typing the command in.
- The agent's launch command appears once, in the shell's history, instead of echoing twice ahead of the prompt.
- Stopping an agent with Ctrl-C leaves you at a normal shell prompt in the same terminal.

### Fixed

- When Claude cannot find the conversation it was asked to resume, the session starts a new conversation and tracks it instead of showing an error.
- A new conversation ID is saved only once its terminal has actually started.
